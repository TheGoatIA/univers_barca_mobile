# Code de conduite

## Notre engagement

Nous nous engageons à faire de la participation à ce projet une expérience exempte de harcèlement pour toutes et tous, quels que soient l'âge, le handicap, l'origine, l'identité ou l'expression de genre, le niveau d'expérience, la nationalité, l'apparence, la religion ou l'orientation sexuelle.

## Comportements attendus

- Faire preuve d'empathie et de bienveillance
- Respecter les points de vue et les expériences différents
- Donner et recevoir les critiques constructives avec élégance
- Se concentrer sur ce qui est le meilleur pour la communauté et le projet

## Comportements inacceptables

- Langage ou images à caractère sexuel, discriminatoire ou haineux
- Trolling, commentaires insultants ou attaques personnelles
- Harcèlement public ou privé
- Publication d'informations privées d'autrui sans autorisation explicite
- Toute autre conduite raisonnablement jugée inappropriée dans un cadre professionnel

## Application

Les comportements inacceptables peuvent être signalés à l'équipe du projet via le signalement privé GitHub (onglet _Security_ → _Report a vulnerability_) ou par e-mail à l'adresse indiquée dans `SECURITY.md`. Toutes les plaintes seront examinées avec discrétion.

Ce code de conduite est adapté du [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
